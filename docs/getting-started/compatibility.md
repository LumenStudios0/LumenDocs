# Compatibility

There is no single compatibility promise for every Lumen Studios product. Check the product's own notes below and match the exact server software, Minecraft release, Java runtime, and dependency versions before installation.

| Product | Documented target or notes |
| --- | --- |
| LumenAuction | Minecraft 1.21.6–1.21.11; Java 21; Bukkit API, including Paper, Spigot/Bukkit, and Purpur. |
| Gladiator | Compiles against Spigot API 1.21.1; Java 21 bytecode. Packet masking requires a compatible PacketEvents version. |
| LumenCosmetics | Bukkit-based servers; Minecraft 1.21+; Java 21. |
| LumenDuels | Plugin descriptor API version 1.21. Optional integrations include PlaceholderAPI, Vault, and WorldGuard. Confirm the jar's Java/server requirements with its release notes. |
| LumenEconomy | Compiles against Paper API 1.21.4; Java 21 bytecode. Paper and Bukkit-compatible forks are intended; newer server versions and each fork/version combination are not all runtime-tested. |
| LumenEssentials | Compiles against Paper API 1.21.11; Java 21 bytecode. Compatible Bukkit-family servers are intended but require runtime verification. |
| LumenOrder | API version 1.21; Java 21+. Paper, Purpur, Spigot, and Bukkit compatibility is documented; Folia is unsupported. |
| LumenShards | Paper 1.21.6–1.21.11; Java 21. |
| LumenSpawners | Compiles against Paper API 1.21.6; API version 1.21. Paper is the only intended platform at this stage; other forks and live runtime support are not verified. |

These are documented build/target notes, not a guarantee that every combination has been tested. Where a product explicitly identifies a runtime limitation, follow that product page.
