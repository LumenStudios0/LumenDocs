# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `/`, `Ctrl+K`, or `⌘K` | Open VitePress documentation search |
| `Ctrl+Shift+A` or `⌘Shift+A` | Open the Lumen Docs Assistant and focus its question box |
| `Escape` | Close the assistant or search dialog |
| `Alt+←` / `Alt+→` | Use your browser’s back and forward history |
