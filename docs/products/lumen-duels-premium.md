# LumenDuels Premium

Premium practice PvP for servers that want more than a quick `/duel`: ranked and unranked queues, Elo, ranks, leaderboards, rewards, cosmetics, and PlaceholderAPI support.

[View LumenDuels Premium on BuiltByBit](https://builtbybit.com/resources/lumenduels-premium.132188/)

## What it does

Set up practice matches and give regulars a reason to keep queuing. Players can work their way through ranked play, follow their Elo and rank progression, and spend rewards in the shop.

## Installation

Download the Premium edition from its BuiltByBit listing and follow the version and setup notes included with that release. It declares Minecraft API version 1.21 and lists PlaceholderAPI, Vault, and WorldGuard as optional integrations.

LumenDuels and LumenDuels Premium are separate editions. Don’t install both on the same server unless the release instructions specifically say that combination is supported.

## Commands

The main command is `/duel` (alias `/duels`). The plugin advertises duel requests, match queues, stats, arena setup, shops, ranks, leaderboards, and kits. Check `/duel` in game and the release notes for the exact commands and permissions in your version.

## Configuration

The Premium repository includes settings for duel behavior, storage, arenas, kits, ranks, shop rewards, GUIs, and messages. Review the files generated by your jar before opening queues—especially inventory cleanup and arena block restoration.
